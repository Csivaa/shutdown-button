# Кнопка выключения компьютера (Arduino Uno + Python)

Проект из 4 файлов:

| Файл | Что это |
|---|---|
| `button_shutdown.ino` | Прошивка для Arduino Uno (загружается через Arduino IDE) |
| `shutdown_listener.py` | Python-скрипт на компьютере: слушает COM-порт и выключает ПК |
| `start_shutdown_listener.bat` | Запускатель для автозагрузки (запускает Python без окна консоли) |
| `README.md` | Этот гайд |

**Как всё работает по цепочке:**
нажатие кнопки → пин D2 замыкается на GND → Arduino отправляет в Serial строку `PRESS` → Python-скрипт читает её из COM-порта → выполняет команду `shutdown /s` → компьютер выключается.

---

## 1. Компоненты

- Arduino Uno + USB-кабель
- Тактовая кнопка: **любая** — с 2, 3 или 4 ножками (см. раздел 2.1)
- Макетная плата (breadboard)
- 2 провода «папа-папа»
- Компьютер с Windows

---

## 2. Схема подключения — дословно, что куда вставлять

### 2.0. А где «+» и «−»? Нужно ли питание на макетку?

**Нет, отдельное питание на макетную плату подавать НЕ нужно, и проводов «плюс»/«минус» в этой схеме тоже нет.** Это вопрос, который путает почти всех, поэтому объясняю подробно.

- Arduino Uno получает питание **от USB-кабеля компьютера**. Сразу после подключения USB на Arduino появляется напряжение.
- На макетной плате есть **две длинные линии по краям** — их часто называют «шины питания»:
  - линия с **красным** рядом отверстий — **«+» (плюс, 5V)**;
  - линия с **синим** рядом отверстий — **«−» (минус, GND)**.
  
  Это удобные «рельсы», по которым удобно разводить питание, **если у вас в схеме много компонентов**. Например, если бы вы подключали целую линейку светодиодов, вы бы взяли один провод 5V с Arduino → на красную линию, один провод GND → на синюю, и дальше всё питание брали с этих линий.
- **Но в нашем проекте всего один компонент — кнопка.** Кнопке не нужно питание: она лишь **замыкает** два провода. Поэтому вся её схема — это **2 провода, и оба идут напрямую к Arduino**:
  - провод от одной ножки → **GND** на Arduino;
  - провод от другой ножки → **D2** на Arduino.
- **В итоге:** к красной («+») линии на макетке мы **не подключаемся вообще**. К синей («−») линии — тоже можно не подключаться (провод GND идёт прямо с Arduino в ряд кнопки).

> **Совет.** Если хотите, можно подключиться через шины питания — схема будет чуть аккуратнее, но это **не обязательно**:
> 1. Провод от **GND** на Arduino → в **любое отверстие синей линии** («−») на макетке.
> 2. Провод от **D2** на Arduino → в **ряд с первой ножкой** кнопки.
> 3. Провод от **ряда со второй ножкой** кнопки → в **любое отверстие синей линии** («−»).
>
> Красную линию («+») в обоих вариантах **не трогаем**.

> **Чего делать нельзя.** Соединять красную линию («+», 5V) с синей («−», GND) напрямую проводом или через кнопку. Это **короткое замыкание** — Arduino может сгореть или выключиться защитой. Наша кнопка соединяет только **GND с пином D2** (низковольтный входной сигнал), а не 5V с GND.

> **Почему без резистора всё безопасно.** В прошивке включена **внутренняя подтяжка** `INPUT_PULLUP`. Arduino сам внутри себя «подтягивает» пин D2 к +5В через встроенный резистор ~20–50 кОм. При нажатии кнопка замыкает D2 на GND — ток через этот внутренний резистор мизерный (меньше 0,25 мА), ничего не греется и не портится. Внешний резистор в такой схеме не нужен.

Итого для всей схемы вам понадобятся ровно **2 провода «папа-папа»**: GND–кнопка и кнопка–D2.

---

Главное правило проекта: **один провод идёт на GND, второй — на D2**. Прошивка и Python-скрипт работают с любой кнопкой — двухножной, трёхножной или четырёхножной, потому что все они при нажатии просто замыкают два контакта между собой.

### 2.1. Кнопка с ДВУМЯ ножками (самый простой случай)

1. Вставьте кнопку в **любые два соседних ряда** макетной платы — одна ножка в один ряд, вторая ножка в другой ряд, через **центральную канавку** (важно: ножки должны попасть в **разные** половины макета, то есть по разные стороны канавки).
2. **Провод №1:** вставьте в отверстие того же ряда, что и **первая ножка** кнопки. Второй конец — в **любой пин GND** на Arduino Uno.
3. **Провод №2:** вставьте в отверстие того же ряда, что и **вторая ножка** кнопки. Второй конец — в **цифровой пин D2** на Arduino Uno.
4. Подключите **Arduino Uno к компьютеру** USB-кабелем.

Схема:

```
Arduino Uno                     Макетная плата
    D2  o───────────────────────o  ряд A: ножка 1 кнопки
   GND  o───────────────────────o  ряд B: ножка 2 кнопки
                                   (ножки 1 и 2 соединяются при нажатии)
```

> **Внимание.** Обе ножки вставьте в **разные** ряды по разные стороны центральной канавки. Если обе ножки кнопки окажутся в одном ряду (или провода подойдут к одной и той же ножке) — цепь будет замкнута всегда, и компьютер выключится сразу после запуска, без нажатия!

### 2.2. Кнопка с ТРЕМЯ ножками

У трёхножной кнопки две ножки соединены между собой постоянно, а третья замыкается при нажатии. Поэтому: **провода подключайте к крайней ножке и средней** (или к двум крайним — зависит от кнопки). Если при проверке в мониторе порта строка `PRESS` появляется **без нажатия** — переставьте провод на другую крайнюю ножку и повторите. Если не появляется совсем — поменяйте ножки наоборот. Один провод всегда на GND, второй всегда на D2.

### 2.3. Кнопка с ЧЕТЫРЬМЯ ножками (как в классическом комплекте)

1. Вставьте кнопку **поперёк центральной канавки** — по две ножки с каждой стороны канавки.
2. Провода подключайте к ножкам **РАЗНЫХ сторон** кнопки (например: левая верхняя ножка → GND, правая верхняя ножка → D2).

---

Резистор не нужен: в прошивке включена встроенная подтяжка `INPUT_PULLUP`, поэтому D2 всегда читается как HIGH (+5В), а при нажатии становится LOW (0В, замкнут на GND). Код прошивки менять не нужно ни для двух-, ни для трёх-, ни для четырёхножной кнопки.

## 3. Прошивка Arduino (Arduino IDE)

1. Скачайте и установите **Arduino IDE** с сайта arduino.cc.
2. Подключите плату USB-кабелем.
3. В Arduino IDE: **Инструменты → Плата → Arduino AVR Boards → Arduino Uno**.
4. **Инструменты → Порт** → выберите COM-порт платы (обычно единственный в списке).
5. **Файл → Открыть** → выберите `button_shutdown.ino`.
6. Нажмите кнопку **«Загрузить»** (стрелка вправо в верхнем левом углу).
7. Проверка: **Инструменты → Монитор порта** (Ctrl+Shift+M), внизу окна скорость **9600**. Нажмите кнопку на макете — должна появиться строка `PRESS`, а светодиод `L` на плате коротко мигнуть.
8. **Обязательно закройте монитор порта и Arduino IDE** — иначе COM-порт будет занят и Python не сможет его открыть.

## 4. Настройка Python на компьютере

1. Установите **Python 3.10+** с python.org. При установке поставьте галочку **«Add python.exe to PATH»**.
2. Откройте командную строку: **Win+R → cmd → Enter** и выполните:
   ```
   pip install pyserial
   ```
3. Положите `shutdown_listener.py` и `start_shutdown_listener.bat` в **одну папку** (например `C:\Users\Даня\Documents\shutdown-button`).

---

## 5. Проверка работы

В командной строке перейдите в папку проекта и запустите:

```
python shutdown_listener.py
```

Скрипт найдёт порт и начнёт слушать. Нажмите кнопку на макете — компьютер начнёт выключение через 5 секунд. Журнал пишется в `shutdown_listener.log` рядом со скриптом.

Если порт не нашёлся автоматически, откройте `shutdown_listener.py` и замените строку:

```python
PORT_NAME = "AUTO"
```

на ваш порт, например:

```python
PORT_NAME = "COM3"
```

## 6. Автозагрузка Python-файла (Windows) — гайд

### Способ 1 (рекомендуемый): папка «Автозагрузка»

1. Нажмите **Win + R**.
2. Введите `shell:startup` и нажмите **Enter** — откроется папка автозагрузки текущего пользователя.
3. В открывшейся папке: **правая кнопка мыши → Создать → Ярлык**.
4. В поле «Укажите расположение объекта» вставьте полный путь к bat-файлу в кавычках, например:
   ```
   "C:\Users\Даня\Documents\shutdown-button\start_shutdown_listener.bat"
   ```
5. Нажмите **«Далее»**, введите имя (например `Кнопка выключения`) и нажмите **«Готово»**.
6. Перезагрузите компьютер и проверьте кнопку.

### Способ 2: Планировщик заданий

1. **Win + R** → введите `taskschd.msc` → **Enter**.
2. Справа нажмите **«Создать простую задачу...»**.
3. Имя: `Кнопка выключения` → **Далее**.
4. Триггер: выберите **«При входе в Windows»** → **Далее**.
5. Действие: **«Запустить программу»** → **Далее**.
6. В поле «Программа или сценарий» укажите путь к `start_shutdown_listener.bat`; в поле «Рабочая папка» — папку проекта → **Далее** → **Готово**.

### Способ 3: через реестр

**Win + R → cmd → Enter**, выполните (подставьте свой путь):

```
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v ShutdownButton /t REG_SZ /d "C:\Users\Даня\Documents\shutdown-button\start_shutdown_listener.bat" /f
```

**Удаление из автозагрузки:** удалите созданный ярлык или задачу, либо выполните:

```
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v ShutdownButton /f
```

### Примечание про `pythonw`

Bat-файл запускает скрипт через `pythonw` (Python без окна консоли). Если автозагрузка не срабатывает, откройте bat-файл в Блокноте и замените слово `pythonw` на полный путь к вашему pythonw.exe, например:

```
"C:\Users\Даня\AppData\Local\Programs\Python\Python312\pythonw.exe"
```

Свой путь узнайте командой `where python` (замените `python.exe` на `pythonw.exe` в пути).

## 7. Как отменить выключение

Кнопка запускает таймер на 5 секунд. За это время нажмите **Win + R**, введите `shutdown /a` и нажмите **Enter** — выключение отменится.

Чтобы выключать мгновенно без таймера, в `shutdown_listener.py` замените:

```python
SHUTDOWN_DELAY_SEC = 5
```

на:

```python
SHUTDOWN_DELAY_SEC = 0
```

## 8. Устранение неполадок

| Симптом | Причина / решение |
|---|---|
| Скрипт пишет «Порт не найден» | Проверьте USB-кабель и драйвер (для клонов — CH340). Либо пропишите `PORT_NAME` вручную. |
| «Ошибка порта ... Access is denied» | Закрыт ли монитор порта / Arduino IDE? Закройте их. |
| Компьютер выключается сразу после запуска скрипта, без нажатия | Оба провода подключены к **одной стороне** кнопки. Переподключите один провод к другой стороне кнопки. |
| Кнопка не реагирует | Откройте монитор порта Arduino (9600) и проверьте, появляется ли `PRESS` при нажатии. Если нет — проверьте провода и пин D2. |
| Автозагрузка не срабатывает | Посмотрите `shutdown_listener.log` рядом с bat-файлом; замените `pythonw` на полный путь (см. раздел 6). |
| Ошибка «pyserial не установлена» | Выполните `pip install pyserial`. |

## 9. Безопасность

- При нажатии кнопки компьютер выключается — **сохраняйте открытые документы заранее**.
- Защита от дребезга (50 мс) и пауза между срабатываниями (3 с) уже встроены в прошивку.
- Задержка 5 секунд перед выключением даёт возможность отменить командой `shutdown /a`.
